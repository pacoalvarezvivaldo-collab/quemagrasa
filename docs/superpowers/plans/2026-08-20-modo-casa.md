# Modo "Casa" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "Casa" (home, bodyweight) training mode to quemagrasa, alongside elíptica/caminadora/escaladora, that assigns a rotating bodyweight exercise (name + GIF) to each interval block instead of numeric machine params.

**Architecture:** Single-file app (`index.html`), no build step. New code is additive: a small data layer fetches `https://cdn.jsdelivr.net/gh/JahelCuadrado/ExerciseGymGifsDB@v1.1.0/api/es/equipment/bodyweight.json` once (lazily, only when Casa mode is used), groups exercises by `category`, and assigns one per interval block. A new `MACHINES.casa` entry plus `if(m.bodyweight)` branches in the existing UI functions render a GIF card instead of the numeric param boxes. The interval-timer engine (`PLANS`, `LEVELS`, `buildPlan` timing, `syncNow`) is untouched.

**Tech Stack:** Vanilla HTML/CSS/JS, `fetch`, `localStorage`. No frameworks, no build tooling — matches the rest of the app.

## Global Constraints

- Media source: `JahelCuadrado/ExerciseGymGifsDB` only, consumed live via jsDelivr CDN URL — never copy/download the GIF files into this repo (see spec's licensing note on why `hasaneyldrm/exercises-dataset` is excluded).
- Pin the jsDelivr URL to tag `@v1.1.0` (not `@main`) so the API shape can't change under us.
- CSP: open only `connect-src` and `img-src` to `https://cdn.jsdelivr.net` — no other CSP directive changes.
- No new dependencies, no build step, no test framework — verify JS changes with `node --check` on the extracted `<script>` body, and one plain `node -e` assert-based check for the pure exercise-assignment logic (per this repo's existing convention — see `[[project-quemagrasa-app]]` memory).
- Every task ends with the app manually opened in a browser and the relevant behavior eyeballed — this app has no automated UI tests.

  - `function assignCasaExercises(intervals: {type:string}[], levelKey: string): void` — mutates each interval in place, setting `.exercise` (an `Exercise` or `null`) and, when an exercise was assigned, overwriting `.name` with the exercise's Spanish name.

  - `function casaCategoryFor(type: string, levelKey: string): string` — like `CASA_CATEGORY_BY_TYPE[type]`, except for `type==='intense'`: returns `'cardio'` (low-impact) for `levelKey` `facil`/`medio`, `'plyometrics'` (explosive/jumping) for `dificil`/`espartano`. This is what makes the same circuit appropriate both for a heavier/deconditioned user on Fácil and a fit user on Espartano — same mechanism as the existing level selector, no new UI.
- Consumes: nothing from other tasks (pure addition).

```js
/* ---------- modo Casa: datos de ejercicios ---------- */
const CASA_URL = 'https://cdn.jsdelivr.net/gh/JahelCuadrado/ExerciseGymGifsDB@v1.1.0/api/es/equipment/bodyweight.json';
const CASA_CATEGORY_BY_TYPE = { easy:'stretching', moderate:'cardio', recovery:'stretching' };
let CASA_STATE = { status:'idle', byCategory:{}, error:null };

async function ensureCasaExercises(){
  if(CASA_STATE.status==='ready') return true;
  if(CASA_STATE.status==='loading') return false;
  CASA_STATE = { status:'loading', byCategory:{}, error:null };
  try{
    const res = await fetch(CASA_URL);
    if(!res.ok) throw new Error('HTTP '+res.status);
    const data = await res.json();
    const byCategory = {};
    data.exercises.forEach(e=>{ (byCategory[e.category] = byCategory[e.category]||[]).push(e); });
    CASA_STATE = { status:'ready', byCategory, error:null };
    return true;
  }catch(e){
    CASA_STATE = { status:'error', byCategory:{}, error:(e&&e.message)||'error' };
    return false;
  }
}

function casaCategoryFor(type, levelKey){
  if(type==='intense') return (levelKey==='dificil'||levelKey==='espartano') ? 'plyometrics' : 'cardio';
  return CASA_CATEGORY_BY_TYPE[type] || 'strength';
}

function assignCasaExercises(intervals, levelKey){
  if(CASA_STATE.status!=='ready'){ intervals.forEach(iv=>{ iv.exercise=null; }); return; }
  const nextIdx={};
  intervals.forEach(iv=>{
    const cat=casaCategoryFor(iv.type, levelKey);
    const pool=CASA_STATE.byCategory[cat]||[];
    if(!pool.length){ iv.exercise=null; return; }
    if(nextIdx[cat]===undefined) nextIdx[cat]=Math.floor(Math.random()*pool.length);
    iv.exercise=pool[nextIdx[cat]%pool.length];
    nextIdx[cat]++;
    iv.name=iv.exercise.name;
  });
}
```
